## Write without switching modes

Plunibio uses Milkdown Crepe to provide visual Markdown editing. You can concentrate on the document while your work remains stored as portable Markdown.

## Work directly with your files

Open a folder as your workspace and move through its files without leaving the application. Breadcrumb navigation keeps your current location clear and constrained to the selected workspace.

## Create, save, and reload

Open a missing path as a new document, save it when it is ready, or reload the version on disk. Plunibio keeps unsaved changes visible and asks before discarding them.

## Find your way around

Search inside text and Markdown documents, browse folders from the sidebar, and return to recent work through the workspace remembered by the application.

## Read more than Markdown

Alongside its visual Markdown editor, Plunibio can open text files and provides dedicated handling for supported content such as images and Mermaid diagrams.

## Use it in your language

The interface follows your system locale and currently includes English and Spanish, with additional translations already taking shape.

> Plunibio is currently an alpha project. Features and interfaces may change before the first stable release.
