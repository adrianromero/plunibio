## Why Plunibio

Markdown is useful because it is simple, readable, and independent of any single application. Plunibio builds on that quality instead of hiding it behind a proprietary library or account.

The goal is a desktop editor that feels calm and modern while continuing to work with ordinary folders and files.

## Built in the open

Plunibio is built with [Tauri](https://v2.tauri.app/), [SolidJS](https://www.solidjs.com/), TypeScript, Rust, and [Milkdown Crepe](https://milkdown.dev/). The source is available on GitHub and contributions are welcome.
