## Empieza aquí

Si es la primera vez que utilizas Plunibio, comienza por [Primeros pasos]({{ '/es/docs/primeros-pasos/' | relative_url }}). Aprenderás cómo se organiza un espacio, cómo abrir un archivo y cómo guardar tu primer cambio.

También puedes ir directamente a una tarea concreta desde el índice. El manual describe el comportamiento de Plunibio y señala expresamente las diferencias entre Windows, Linux y macOS cuando afectan a un procedimiento.
